A one-star review written by a house cat about its human — one line, at
most 200 characters. `LINE.txt` holds the review; `main.ts` checks it is a
single line of 1 to 200 characters and writes it to `/output/entry.txt`
for the judge to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
